# 🏦 Smart Bank System

A full-featured desktop banking application built using Java, Swing, and MySQL.  
This project demonstrates core Object-Oriented Programming (OOP), database integration using JDBC, and GUI-based user interaction.

---

## 🚀 Features

- 🔐 User Registration & Secure Login
- 💰 Deposit & Withdrawal System
- 📊 Real-time Balance Viewing
- 🧾 Transaction History Tracking
- 🗄️ MySQL Database Integration
- 🖥️ Interactive Swing-based GUI
- 💾 Persistent Data Storage

---

## 🛠️ Technologies Used

- Java (OOP Principles)
- Swing (GUI Development)
- MySQL (Database)
- JDBC (Database Connectivity)
- Git & GitHub (Version Control)

---

## 🧠 Concepts Implemented

- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Exception Handling
- File Handling (Earlier version)
- JDBC & SQL Queries
- Prepared Statements (SQL Injection Safe)

---

## ⚙️ Setup Instructions

1. Install MySQL
2. Create database `smartbank`
3. Create required tables
4. Add MySQL Connector JAR
5. Run `Main.java`
